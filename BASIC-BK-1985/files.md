# Файлы исходного кода Бейсик-Вильнюс для БК-0010 (1985)

Исходники BASIC-BK-1985 - Бейсик Вильнюс (ВЦКП ВГУ, графический модуль - ИПИ АН СССР) для БК-0010, вариант для ПЗУ (адреса `120000`-`177577`) с числами двойной точности. Они почти точно соответствуют Бейсику из ПЗУ БК-0010 (см. `../BASIC-BK-0010-19860724/README.md` - там список отличий и сборка, побайтно совпадающая с ПЗУ 1986.07.24).

Модули находятся в одном каталоге; сборка из них - ПЗУ `120000`-`177577`. Порядок линковки взят из `../BASIC-BK-0010-19860724/!link.cmd` (там он выверен сборкой, побайтно совпадающей с ПЗУ): `BK MONIT COMP TRAP JMP FLOAT TAIL`. Объектных модулей семь: `BK.OBJ` (собран из двух файлов, `BK.MAC` и `GRAF.MAC`, как один модуль: `BK.MAC` заканчивается внутри открытого `.IF EQ,MASINA-BK0010`, `GRAF.MAC` закрывает его и содержит `.END START`), `MONIT`, `COMP`, `TRAP`, `JMP`, `FLOAT` и `TAIL`. `TAIL.MAC` (хвост ПЗУ: слово и байт по адресам `177530` и `177577`) есть только в каталоге пересборки 1986 года, в исходниках 1985 его нет. Порядок разделов ниже - тот же, но без `TAIL`. Общие сведения об устройстве (условная сборка, память, типы, TRAP-библиотека, монитор ПЗУ БК) - в `README.md`.

Файлы `.MAC` - UTF-8 с BOM, CRLF, табуляция.

## 1. `BK.MAC` (+ `GRAF.MAC`)

**Назначение:** конфигурация, системные переменные, пуск, ввод-вывод, отладка STEP.

- **Блок настройки и константы** (`MASINA`, `MEMTYP`, `KONTYP`, векторы `BREAKW`, `TRAPW`, `TIMER`, `MAG`, `IRPSW`, порты `ARPORT`/`ASPORT`).
- **Переменные:** `LYGIS` (режим: `0` монитор, `#400` прямой оператор, `<0` выполнение программы, `1` листинг, `#200` перенумерация), `TXEND`, `ENDCOD`, `STRREG`/`STRSIZ`/`FREBEG`/`FRELEN`, `CIKL`/`LIMIT`, `LENT`/`TABTOP`/`FCB`, `HIMEM`, `ERRS`, `TYPE`, `DATBEG`/`DATPTR`/`DATINP`, `NUMBER`, `ADRHLT`, `TRFLAG`, `AUTOON`/`AUINC`, `CURLIN`, `III`/`RNDSAV` (RND), `USRTAB`, `PFACT`, `TMP`, `SAVJMP`, `LPTPOS`, `FNKSTR`, `IODEV`, `INK`, `BUF`, `BUFOUT`.
- **`START`:** проверка контрольной суммы ПЗУ (в сборке ПЗУ 1986.07.24 отключена), начальные значения, `CLRTXT`, `KINIT`, `SETW`. `SUM1` - балансирующее слово суммы.
- **`CTRLC`, `BREAK`, `SETW`:** клавиша СТОП, векторы прерываний.
- **`MIDM`, `KINIT`, `ISVSS`:** инициализация монитора, функциональные клавиши и их строка на экране.
- **`IVEIL`:** экранный редактор строки (EMT 6/16, коды управления, ГРАФ, клавиша STEP), `PELING`, `SSE`.
- **`ISV`, `ISVEIL`, `ISVETO`, `ISVTO`, `LP`/`LPISV`, `FILOUT`/`COPOUT`:** вывод на экран, принтер (порт `ARPORT`) и в файл.
- **`STEP`, `TRIN`, `NEXPAP`, `HCOR`, `REPA`, `SEPAP`, `STPEND`:** временные точки останова. `STEP`/`TRON` находят следующий оператор (включая ветви GOTO/GOSUB/FOR), подменяют слово кода переходом на `STPEND`; `SEPAP` снимает все такие точки и сбрасывает стек интерпретатора (вызывается при любом выходе из выполнения).
- **`CURON`/`CUROFF`, `INKEY`, `MAGNIT`, `USEROM`, `ADDRMN`, `LOC`, `ZONA`, `TAB`, `AT`, `LOCX`/`LOCY`, `$KEY`:** курсор, клавиатура, подключаемое ПЗУ (`CALL`), позиционирование, функциональные клавиши.
- **`IRPS`/`IVT`/`ISVT`:** обмен через последовательный интерфейс ИРПС (префикс `TT:`).
- Значительная часть файла - ветви `.IFF` для других машин, не входящие в сборку.

**`GRAF.MAC`** (продолжение того же модуля): графика через монитор БК. Цвет (`COLF`/`COLR`, коды драйвера `220`-`224`), курсор (`CURCOR`, `STP`, `LSTP`), `SET`/`RESET` (PSET/PRESET), `LSET` (LINE), `RECSET`, `BOXSET`, `POINT`, закраска `$PAINT` (сканирование по строкам со стеком подобластей), дуги и круги `$ARC` (алгоритм по квадрантам и симметричным точкам, `ANG1`/`ANG2`, `ASPINT`/`ASPDBL`/`ASPSNG` - сжатие), оператор DRAW (`$DRAW`, команды M N B C S A X и направления). Старый вариант `$DRAW` и упрощённые `COLF`/`COLR` под `.IFF` в сборку не входят. Заканчивается `.END START`.

## 2. `MONIT.MAC`

**Назначение:** монитор (цикл "Ok"), таблицы операторов, запуск компиляции и выполнения, команды монитора.

- Таблицы: `OPRNAM` (имена операторов), `AOPNAM` (адреса имён), `AOPSUB` (программы компиляции операторов), `AOPMON` (команды монитора).
- `MONIT`, `STAR`, `ANALIZ`, `ASCCOD` (классификация введённой строки: строка программы или директива), `COMAND`, `STATM` (прямой оператор), `DEL`.
- `CLRBUF`, `CLRTXT`, `CLRCOD`, `STRMEM`, `NEW`.
- `LIST`/`LLIST`, `EDIT`, `AUTO`, `RENUM` (перенумерация с переписыванием ссылок через `KODTST`/`IFGAUD`/`RENPAP`), `DELETE`, `GRBCOL` (уплотнение текста).
- `RUN`/`LRUN`/`COMPIL`/`ENDTXT`: компиляция всей программы, разрешение ссылок вперёд (`SETST`, цепочка в служебном слове строки), перенос DATA в код, цепочка `AUTOON` для `RESTORE` без номера; `VYKDYT` - запуск выполнения; `CONT`.
- **Магнитофон:** `LOAD`, `SAVE`, `CLOAD`, `CSAVE`, `BLOAD`, `BSAVE`, `FIND`, `FILNAM`, `TTANAL`, `CAS`/`CASERR`, `BLOCKN`, `ASC`/`COD`/`BIN`/`DAT`. Блок параметров монитора БК `MAG`: команда, результат, адрес, длина, имя (16 байт), данные найденного файла. Текст сохраняется блоками по 256 байт с именем вида `.ASC # 000`.
- `IUNPCK`/`I1` - целое в десятичный текст.

## 3. `COMP.MAC`

**Назначение:** программы компиляции операторов (по таблице `AOPSUB` из `MONIT.MAC`): `PRINT`/`LPRINT`, `LOCATE`, `LET` (в том числе `MID$=`), `RETURN`, `GOTO`/`GOSUB`, `IF`, `FOR`, `NEXT`, `STOP`, `END`, `TRON`/`TROFF`, `DATA`, `RESTORE`, `READ`, `INPUT`, `CLEAR`, `DIM`, `POKE`, `OUT`, `COLOR`, `BEEP`, `CLS`, `PSET`/`PRESET`, `LINE`, `KEY`, `CIRCLE`, `PAINT`, `DRAW`, `DEF`, `ON`, `OPEN`/`CLOSE`, `CALL`. Служебное: `TSTSQZ`, `TSTLYG`, `TSTFLN`/`TSTFIL`, таблицы слов (`RWREN`, `RWIF`, `RWPRIN`...). `SUM2` - балансирующее слово контрольной суммы.

Каждая программа получает `R1` - указатель записи кода, пишет в него опкоды и операнды и разбирает текст через `TRAP`. Ссылки на строки, которые ещё не скомпилированы, образуют связный список в служебном слове строки.

## 4. `TRAP.MAC`

**Назначение:** диспетчер `TRAP` и библиотека разбора.

- `TRAP`, `ERROR` (печать "ОШИБКА n", затем по `LYGIS`), `RUNERR`, `GETERR`, `MONERR`.
- Таблица `ATRAP`: `T100` - выражение (приоритеты логических операций, затем отношения `SANT`, сумма `SUDAT`, `MOD`, `\`, `*` `/`, `^`, операнд `OPER`), `T101` - символ из списка, `T102` - буква/цифра/другое, `T103` - переменная или элемент массива, `T104` - поиск/создание переменной, `T105` - имя (четыре варианта возврата: числовая функция, строковая функция, строковая переменная, числовая переменная), `T106` - конец оператора, `T107` - имя переменной, `T110` - номер строки, `T111` - поиск строки, `T112` - пропуск пробелов, `T113` - поиск ключевого слова в таблице (второй операнд: режим 1-2 допускает сокращение, 3 и выше - только целиком; старший байт - последнее слово для проверки), `T114` - вывод числа, `T115` - строковое выражение, `T116` - необязательный аргумент, `T117` - цифры с точкой, `T120`-`T122` - строковые литералы, `T123`-`T125` - один-три целых аргумента, `T126` - запятая, `T127`/`T130` - скобки.
- `CINT`/`CSNG`/`CDBL`, `CISLO` (числовой литерал, в том числе `&B`/`&O`/`&H`), `BOHPAP`, `USR` (вызов USR и FN), `LMID`, строковые функции (`SIMFUN`, `STRING$`, `STR$`...), таблицы `FUN`/`SFUN`/`AFUN`.

## 5. `JMP.MAC`

**Назначение:** исполняющая часть: опкоды шитого кода.

- Управление: `TRUN`, `TREND`, `ENDPRG`, `HALT`, `IFT`/`IFF`, `JMP`, `JSR`, `RTS`, `RTSTO`, `ONJMP`/`ONJSR`, `FORINT`/`FORDBL`, `NEXINT`/`NEXDBL`/`NEXSNG`, `NXSKIP`.
- Функции пользователя: `DFN`, `FNST`, `FNCALL`, `APAR`, `IPAR`/`SPAR`/`DPAR`, `IFNRET`/`SFNRET`/`DFNRET`.
- Константы и переменные: `DCONST`/`SCONST`/`ICONST`, `DVAR`/`SVAR`/`IVAR`, элементы массивов `*XVAR`, присваивание `*MOV`/`*XMOV`, `MIDMOV`.
- Сравнения: `ICMP`, `SCMP`, `DCMP`, `$CMP`, `ADDRBR`.
- Вывод и ввод: `LIT`, `SOUTSP`/`DOUTSP`/`IOUTSP`, `GET`/`GETLIT`/`READV`/`GETARR` с `TODBL`/`TOSNG`/`TOINT`.
- Массивы: `INDEX`, `ARRAY`, `ARR10`, `DAUG`.
- Строки: `NEWSTR`, `TSTFRE`, `CONCAT`, `STR`/`STR2`, `ALLSK`/`ALLSM`, `CHR`, `LEN`, `ASC`, `VAL`, `STR$` (`SSTR`/`DSTR`/`ISTR`), `OCT`/`BIN`/`HEX`; сборка мусора `STRSQU` (с `FIND`, `PERK`, `MASREG`, `SSQ1`, `SSQ2`). Временные строки в БК не регистрируются списком - обход идёт по таблице переменных.
- Память и файлы: `CLR`/`CLRSTR`/`CLRMEM`, `TABMOV`, `OPINP`/`OPOUT`, `NAMTYP`, `DEVICE`/`CLRDEV`/`DEVLP`, `CLOALL`/`CLOF`/`CLOUTF`, `EOF`, `FILINP`/`COPYIN`.
- Прочее: `POKJMP`, `OUTJMP`, `PEEK`, `INP`, `FRE`, `$FRE`, `$USR`, целые операции `SUM`/`SKIRT`/`SAND`/`IDIV`/`MOD`, логические `NOT`/`OR`/`AND`/`XOR`/`EQV`/`IMP`.

## 6. `FLOAT.MAC`

**Назначение:** вещественная арифметика двойной и одинарной точности и преобразования.

- `PACK` (текст в число; результат - четыре слова, сверху слово статуса, бит 0 которого равен 1, если в тексте была буква `E`, то есть одинарная точность), `EGO`/`DGO`/`UNPCK` (число в текст), вспомогательные сдвиги и умножения на 5/4, 4/5, 5 (`PDAUG2`, `PDAUG5`, `PD5DL4`, `DG5DL4`, `DG4DL5`, `UDAUG8`, `ROUND1`).
- Преобразования типов `IS`/`SI`/`ID`/`SD`/`DI`, знак и модуль (`IABS`, `ISGN`, `SSGN`, `ABS`), `PI`.
- Арифметика: `$DADD$`/`$DSUB$`, `$DMUL$`, `$DDIV$`, нормализация `$FNORM`.
- Функции: `SQR` (`$B91`), `SIN`/`COS`/`TAN`/`ATN` (`$B93`/`$B95`/`$TAN`/`$B97`), `EXP`/`LOG` (`$B99`/`$B103`), `RND` (`RAN`), `$FRACT`, `$FIX`, `$INT`, `$APPRX`, `POW`, `DCMP`.
- Подробно прокомментированы `PACK`, `UNPCK` и вспомогательные подпрограммы; тела арифметики и функций в основном остаются с оригинальными английскими комментариями.
