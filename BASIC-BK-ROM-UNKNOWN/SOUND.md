# Оператор SOUND (BASIC-BK-ROM-UNKNOWN)

Выводы получены чтением кода (`basic-rom.dis.lst`, метки `C.SOUND`, `SND.ARGS`, `R.SOUND`, `NOTETAB`); оператор в эмуляторе не запускался. В базовом ПЗУ 1986.07.24 `SOUND` нет (есть `BEEP` — вывод кода 7 в канал, `162030`).

## Синтаксис и компиляция

`SOUND a, b` — два целых выражения через запятую. `C.SOUND` (`142104`): `CALL SND.ARGS` (`142202`: `TRAP 100` выражение, `CALL CINT`, запятая через `TRAP 112` и `CMPB #54`, снова выражение и `CINT`; нет запятой — `TRAP 2`, синтаксическая ошибка), затем в код пишется адрес `R.SOUND` и общий хвост `TRAP 106`. Проверок диапазона на уровне Бейсика нет, только приведение к целому.

## Исполнение (`R.SOUND`, `164262`)

Из стека: сверху **второй** аргумент `b` — нота, под ним первый `a` — длительность.

- Нота `n = b`: `R2 = n + 24`; если `R2 < 0` или `2*R2 > 120` (`CMP R2,#170`), полупериод `R0 = 0` (65536 шагов — практически пауза). Иначе слово из `NOTETAB` (`122100`) по индексу `2*(n+24)`: младший байт — полупериод в шагах, старший — добавка задержки.
- Таблица: 60 слов, ноты −24…35, полупериод 147 при −24 и вдвое меньше через каждые 12 нот (36 при 0, 18 при 12, 9 при 24): равномерно-темперированный строй, 12 нот на октаву. Нота 0 — полупериод 36 шагов.
- Звук: запись `340` и `200` в системный порт `177716` (разряд `100` — динамик БК-0010; значение остальных разрядов не проверялось), между записями `R0` шагов цикла `SOB` (три пустых `CMP #340,#340` на шаг). Два периода подряд, потом добавочная задержка (`SOB` по старшему байту таблицы) и снова.
- Длительность: каждый шаг уменьшает `R1` (начальное значение — `a`); при нуле уменьшается внешний счётчик `R3` (начальное `454` = 300 дес.) и `R1` берётся заново. Всего примерно `a * 300` шагов, от высоты ноты не зависит (у высоких нот больше периодов). `a = 0` даёт 65536 * 300 шагов (очень долго).
- `R4` (указатель нитевого кода) на время звука сохраняется в `SAVJMP` (`2150`), в конце восстанавливается, `SAVJMP` обнуляется; порт возвращается в `200`.

## Код исполнения

Адрес, слова и текст из `basic-rom.dis.lst`, комментарии добавлены. Регистры: `R0` — полупериод в шагах, `R1` — счётчик длительности, `R5` — его начальное значение, `R3` — внешний счётчик, `R2` — счётчик шагов, `R4` — счётчик периодов. В стеке под нотой лежит добавка задержки.

```
R.SOUND:
164262  MOV   R4,2150           ; спрятать указатель нитевого кода (R4 понадобится как счётчик)
164266  MOV   #454,R3           ; внешний счётчик = 300.
164272  MOV   (SP)+,R2          ; R2 = нота (второй аргумент)
164274  MOV   (SP)+,R1          ; R1 = длительность (первый аргумент)
164276  MOV   R1,R5             ; R5 = запас для перезагрузки R1
164300  CLR   R0                ; R0 = 0 (полупериод "пауза", если нота не в диапазоне)
164302  ADD   #30,R2            ; номер в таблице = нота + 24
164306  BMI   SND.NOTE          ; < 0 => R0 остаётся 0
164310  ASL   R2                ; слово таблицы = 2 байта
164312  CMP   R2,#170
164316  BHI   SND.NOTE          ; за пределами => R0 остаётся 0
164320  BISB  122100(R2),R0     ; R0 = полупериод (младший байт слова NOTETAB)
SND.NOTE:
164324  MOVB  122101(R2),-(SP)  ; в стек - добавка задержки (старший байт слова)
SND.CYC:
164330  MOV   #2,R4             ; два периода подряд
SND.HI:                         ; ---- полупериод "1"
164334  MOV   #340,@#177716     ; порт = 340: динамик в 1
164342  MOV   @#177716,R2       ; (чтение порта, результат тут же затирается)
164346  MOV   R0,R2             ; R2 = число шагов полупериода
164350  BR    L164374           ; первый шаг без пустых CMP
L164352:                        ; ---- шаг полупериода
164352  CMP   #340,#340         ; три пустых CMP - задержка шага
164360  CMP   #340,#340
164366  CMP   #340,#340
L164374:
164374  DEC   R1                ; счётчик длительности
164376  BNE   L164406           ; не ноль => к концу шага
164400  DEC   R3                ; ноль: внешний счётчик
164402  BEQ   SND.END           ; весь звук отыгран => конец
164404  MOV   R5,R1             ; R1 заново
L164406:
164406  SOB   R2,L164352        ; шаги полупериода
SND.LO:                         ; ---- полупериод "0" (то же самое с портом 200)
164410  MOV   #200,@#177716     ; порт = 200: динамик в 0
164416  MOV   @#177716,R2
164422  MOV   R0,R2
164424  BR    L164450
L164426:
164426  CMP   #340,#340         ; (три пустых CMP)
164434  CMP   #340,#340
164442  CMP   #340,#340
L164450:
164450  DEC   R1                ; (длительность, как в первом полупериоде)
164452  BNE   L164462
164454  DEC   R3
164456  BEQ   SND.END
164460  MOV   R5,R1
L164462:
164462  SOB   R2,L164426
164464  SOB   R4,SND.HI         ; второй период
164466  MOVB  (SP),R4           ; R4 = добавка задержки
SND.TRIM:
164470  SOB   R4,SND.TRIM       ; ждать добавку (подгонка частоты)
164472  BR    SND.CYC           ; снова два периода
SND.END:
164474  MOV   #200,@#177716     ; порт = 200: динамик в 0
164502  TST   (SP)+             ; снять добавку со стека
164504  MOV   2150,R4           ; вернуть указатель нитевого кода
164510  CLR   2150
164514  JMP   @(R4)+            ; следующий оператор
```

Как получается звук: цикл `SND.HI` .. `SND.LO` — это один период меандра (порт 340, потом 200), каждая половина длится `R0` шагов. Два периода подряд, затем пауза `SND.TRIM` и снова. Шаг одинаков по времени для обеих половин, поэтому частота определяется только `R0` и добавкой из таблицы. `DEC R1`/`R3` стоят прямо в шаге: они считают те же шаги и поэтому задают общую длительность `a * 300` шагов, не зависящую от ноты. В первом проходе каждой половины три `CMP` пропускаются (`BR L164374`), так что полупериод из `R0` проходов содержит `R0 - 1` задержек по три `CMP`.

## Подозрения на ошибки оригинала

- Допустимый индекс до `170`, то есть нота 36, а таблица кончается нотой 35: нота 36 берёт слово `334 277` за таблицей (полупериод 220, задержка 191).
- Стоп клавишей (CTRL/C) во время звука не проверяется.
