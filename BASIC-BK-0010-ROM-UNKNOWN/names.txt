N 164324 SND.NOTE
K 164324 R0 = делитель полупериода из NOTETAB (младший байт слова), в стек - добавка задержки (старший байт); нота вне диапазона: R0 = 0, т.е. 65536 шагов на полупериод (практически тишина)

K 164330 два периода меандра подряд (R4 = 2), затем добавочная задержка из таблицы и снова сюда
N 164334 SND.HI
K 164334 полупериод "1": порт = 340; R2 = R0 шагов; каждый шаг: 3 пустых CMP, DEC R1; по R1 = 0 - DEC R3 (внешний счётчик 300.) и R1 = длительность заново
N 164410 SND.LO
K 164410 полупериод "0": порт = 200, те же R0 шагов
N 164470 SND.TRIM
K 164470 добавочная задержка: SOB R4 по байту из NOTETAB (MOVB знаковый: в таблице значения < 128)
N 164474 SND.END
K 164474 конец звука (R3 = 0): порт = 200 (динамик в 0), снять добавку, R4 из SAVJMP, SAVJMP = 0, дальше по нитевому коду
N 122100 NOTETAB
K 122100 таблица нот SOUND: слово на ноту, 60 слов (ноты -24..35 после ADD #30,R2; индекс ASL 2*(n+24)): младший байт - полупериод в шагах (147 при -24, вдвое меньше на каждые 12 - равномерно-темперированный строй, 12 нот на октаву), старший - добавочная задержка для подгонки.
