# Turbo Basic для УКНЦ

Turbo Basic для УКНЦ - Олег Герасимов, 1994-1995 (баннер в `START.MAC`: «The Turbo Basic, Copyright (C) 1994 to 1995, by Gerasimov Oleg»). Это потомок Бейсика-Вильнюс (см. [`../BASIC-UKNC-DSK-1988-NEW/files.md`](../BASIC-UKNC-DSK-1988-NEW/files.md)): ядро компилятора и интерпретатора шитого кода унаследовано от версии 1988 г. почти без изменений, но вокруг него построена другая система - интегрированная среда (IDE) с окнами и редактором, работающая в периферийном процессоре (ПП), и драйвер графики для ПП. Бейсик выполняется в центральном процессоре (ЦП).

Правила кодировки: все `.MAC`, `IDE.DEF` приведены к UTF-8 с BOM (исходно CP866, хвостовой паддинг NUL до 512 байт удалён). `IDE.MLB`, `TAB.TXT`, `TABF.TXT` - чистый ASCII, в базовом коммите оставлены как есть.

**Что проверено, а что нет.** Описания ниже получены чтением исходников и построчным сравнением с версией УКНЦ 1988 (отброшены комментарии и пробелы). Сборочные командные файлы (`BUILD.COM`, `BASIC.COM`, `IDE.COM`) удалены из каталога, но сохранены отдельно (`D:\Work\MyProjects\uknc-various\TURBO-BASIC`, read-only); их содержимое приведено в разделе «Сборка». Тексты `.MAC` в той копии совпадают с каталогом (кроме NUL-паддинга). Всё, что названо «вероятно», подлежит проверке.

## Общая картина

В УКНЦ два процессора: ЦП (основной) и ПП (периферийный: клавиатура, диски, видеопамять, терминал). Обмен идёт через канальные регистры `176674`/`176676` (`MCSR`/`MDBR` в `IO.MAC`) и общие ячейки.

Четыре исполняемых части (по `XLINK.MAC`: `Start.Sav`, `Ide.Sav`, `Basic.Sav`, при желании `OutScr.Sav` - в таблице `Itab` строка `i2` закомментирована):

| Часть | Модули | Где работает |
| --- | --- | --- |
| Загрузчик | `START.MAC` | обычная программа RT-11 (`.Asect`, адрес 1000) |
| IDE (среда) | `IDE.MAC`, `WINDOW.MAC`, `EDIT.MAC`, `UPEXEC.MAC`, `MEMORY.MAC`, `VAR.MAC`, `IDDAT.MAC`, `IDDAT2.MAC`, `HELP.MAC`, `ERMSG.MAC`, макробиблиотека `IDE.MLB`/`IDE.DEF` | инсталлятор (секция `Install`) - ЦП, остальное - резидент в памяти ПП |
| Турбо-графика | `TGRAPH.MAC` (линкуется последней в `Ide.Sav`; `FONT` там же) | ПП (ставится `TGINST`; `TGLoad`/`TgSwap` в `MEMORY.MAC` обменивают её с окном памяти ПП) |
| Бейсик | `DT`, `MONIT`, `TABL`, `IO`, `PPIO`, `TRAP`, `COMP`, `JMIN`, `JMP`, `JEXT`, `DISK`, `GRAFUK`, `FLOATS` (`GENUKD` - включаемый файл) | ЦП |

Схема работы (протокол ЦП-ПП - в разделе `PPIO.MAC`): `IdeIni` (инсталлятор в ЦП) запрашивает у ПП память командой `Mp.All`, переносит туда резидент (`Begin`..`PpStp`) с релокацией по таблице `Rtab`, запускает его (`Mp.Exe`) и ставит Турбо-графику (`TGINST`). Резидент перехватывает в ПП векторы `100` (таймер), `300` (клавиатура), `34` (TRAP) и открывает редактор (`$Edit`). Когда пользователь жмёт «компилировать/выполнить», IDE по `TRAP #0` (`INT34`, номер 0 - «диспетчер процессов») вызывает `CmAppl`, а ЦП исполняет Бейсик: через `INT104`/`PCOD` (`PPIO.MAC`) ЦП-Бейсик получает от IDE коды операций (открыть, прочитать, компилировать блок, запустить и т.п.), а файловый ввод-вывод Бейсика обращается к RT-11 (`DISK.MAC`, `PPIO.MAC`).

Исходные тексты хранятся в виде обычных текстовых файлов `.BAS`, результат компиляции - объектные файлы `.TBO` (`TboCre`/`LdObj` в `PPIO.MAC`, `DefTbo`; идентификатор в заголовке - адрес `Text`). Это отличие от 1988 года: там компиляция и выполнение происходили в одной программе, текст строк хранился в памяти.

## Сборка

`BUILD.COM` (RT-11) ассемблирует все модули и собирает два образа:

```
Macro Start,Dt,Monit,PPIO,IO
Macro Jmp,Jmin,Jext,Disk,Comp,Trap
Macro Floats,Tabl,Grafuk,Ide,Window
Macro Edit,UpExec,ErMsg,Font,Iddat
Macro Iddat2,Var,Tgraph,Memory,Help
R Link
Basic=//
Dt,Monit,Tabl,Io,PpIo
Trap,Comp,Jmin,Jmp,Jext
Disk,Grafuk,Floats
//
Ide=//
Dt
Ide,Memory
UpExec,Edit,ErMsg
Window,Help,IdDat
IdDat2,Font,Var
TGraph
//
xLINK
```

`BASIC.COM` и `IDE.COM` собирают `Basic.Sav` и `Ide.Sav` по отдельности теми же списками. Итог: `Basic.Sav` = `DT`, `MONIT`, `TABL`, `IO`, `PPIO`, `TRAP`, `COMP`, `JMIN`, `JMP`, `JEXT`, `DISK`, `GRAFUK`, `FLOATS`; `Ide.Sav` = `DT`, `IDE`, `MEMORY`, `UPEXEC`, `EDIT`, `ERMSG`, `WINDOW`, `HELP`, `IDDAT`, `IDDAT2`, `FONT`, `VAR`, `TGRAPH`. Заключительный `xLINK` - упаковщик (`XLINK.MAC`); `Start.Sav` собирается из `START.MAC` отдельно. `DT.MAC` линкуется в обе части (общая область переменных от `STACK = 1000`), а `TGRAPH` и `FONT` входят в `Ide.Sav`, а не в Бейсик.

## Служебное

### `START.MAC` - загрузчик

Прокомментирован. Программа для RT-11 (`.Asect`, `.=40`: слова `Start,Start,1000,0,2000` - старт, SP, JSW, USR, верхняя граница). Печатает баннер (`.PRINT`), расшифровывает таблицу оверлеев с адреса 1400 (200 слов; запись - 3 слова: адрес, длина в словах, номер блока), затем читает по записям части `Ide.Sav` и `Basic.Sav` через канал 17 (`.ReadW 17`, файл `Turbo.Sav`), расшифровывает каждую вызовом `Crypt` и вызывает по её адресу (`Call @-6(R5)`). Часть, вернувшая C = 1, завершает работу; ошибка чтения - сообщение и `.EXIT`. `Crypt` - потоковый шифр: пара `R0:R1` с начальным значением `^rOWG`/`^rELJ` (24927. и 8490.) сдвигается влево (`Ashc R5,R0`), при смене знака в `R1` ставится бит 5, слово данных XOR `R0`; шифрование и расшифровка совпадают. Таблицу и части шифрует `XLINK.MAC` тем же алгоритмом. Нулевая запись таблицы не проверяется (длина 0 в `Crypt` дала бы 65536 слов); модуль защищает `Turbo.SAV` от простого просмотра.

### `XLINK.MAC` - упаковщик (Tlink)

Прокомментирован. Утилита для RT-11 (баннер `Tlink-U-`, не выводится): создаёт `DK:Turbo.Sav` из `Start.Sav`, `Ide.Sav`, `Basic.Sav` (строка `OutScr.Sav` в `Itab` закомментирована). Первые 1000 слов `Start.Sav` (загрузчик и таблица с адреса 1400) идут в блоки 0-1; для каждой части читается весь файл, в запись таблицы пишутся адрес (слово 40 части), длина в словах ((слово 50 - слово 40) / 2 + 1) и номер блока, образ шифруется `Crypt` (тот же ключ `^rOWG`/`^rELJ`, шифр заново с начала для каждой части) и записывается с этого блока; следующий блок - плюс длина/256 + 1. В конце шифруется таблица (200 слов) и записывается блок 0-1. Загрузчик не шифруется (вызовы `Crypt` для него закомментированы). Не используются: `DevExt`, `FileBuffer`, сообщения кроме `IError`, `.CsiSpc`. Размер частей ограничен памятью (`.Settop #-1`).

### `ENDTRC.MAC` - оптимизатор текстов

Прокомментирован. Отдельная утилита RT-11 («Text files optimiser», приглашение `EndTrc>`): команда по правилам CSI (`.CsiGen`, расширение по умолчанию `.LST`, выход - канал 0, вход - канал 3) копирует текстовый файл блоками по 512 байт через `IBuff`/`OBuff`, убирая пробелы в конце строк (строка кончается `CR,LF`). Конец текста - нулевой байт; длина строки до 256 байт не проверяется. Ошибки ввода-вывода и разбора команды печатаются по коду из ячейки 52. Возможная ошибка автора: при нечётном `WrPtr` в `BWrite` (запись последнего блока из `Close`) `Clr (R0)+` обращается к нечётному адресу. К Бейсику и IDE отношения не имеет.

### `IDE.MLB`, `IDE.DEF`

`IDE.DEF` - общие определения (режим памяти `MemTyp = Base/Extend`, версия `Version`, защита `SavPrt`, `On`/`Off` и т.п.). `IDE.MLB` - библиотека макросов: `PUSH`/`POP` (список операндов), `CONCAT`, `LOCATE`/`LOC`, `IF` (макрос условного перехода с символьными отношениями `=`, `{}`, `}`, `{=` ...), `.COLOR`/`.WIND`/`.BUTON`/`.EDIT`/`.USER`/`.ENDS` (описание окон-меню), `WINDOW`, `WCLOSE`, `PRINT`, `PRINTN`, и главное `.RelDef`/`Rel` - макрос релокации: каждая команда с абсолютным адресом, помеченная `Rel`, регистрирует своё слово в секции `RelTab`, чтобы инсталлятор мог сдвинуть резидент при загрузке в ПП (`Rtab`).

### `TAB.TXT`, `TABF.TXT`

Списки ключевых слов с номерами: `TAB.TXT` (заголовок `L`) - операторы (`DIM`=2, `LET`=11, `REM`=19... `CLOAD`=66; номера 1 и 13 в файле отсутствуют - по `CMPRET` в `SEEKOP` односимвольные слова апостроф (`REM`) и `?` (`PRINT`) получают коды 1 и 13; в т.ч. новые `REPEAT`/`UNTIL`/`WHILE`/`WEND`, `GET`/`PUT`, `PALETTE`, `SOUND`, `FSOUND`, `NOSOUND`, `PAGE`, `DELAY`, `FPUT`/`FGET`/`FSAVE`/`FLOAD`, `SMODE`, `_CREATE`/`_CLOSE`/`_OPEN`/`_READ`/`_WRITE`/`_PURGE`), `TABF.TXT` (заголовок `F`) - функции `PI`..`HEX$` (0-37). Номер - индекс в таблице `AOPSUB` (`COMP.MAC`) или функций.

### `TABL.MAC`

Прокомментирован (шапка и хвосты; файл сгенерирован, генератора в каталоге нет, при перегенерации комментарии пропадут). Таблицы поиска ключевых слов (по `TAB.TXT`/`TABF.TXT`): корни `L0000` (операторы) и `F0000` (функции) - 32-словные таблицы по первой букве, ведущие к спискам узлов (`Trees$`) по следующим буквам с «хвостами» (`Tails$`, `.Ascii <код>/ОСТАТОК/<40>`). Слово узла: 5 бит буквы + (смещение до следующего списка или хвоста в байтах) << 5; список упорядочен по буквам, конец - `-1`. Хвост: код слова (восьмеричный; в `TAB.TXT`/`TABF.TXT` десятичный), остаток текста, конец `40` (операторы) или `200` (функции). Деревья проверены скриптом: 64 оператора и 38 функций, коды совпадают с текстовыми таблицами. Просмотр - `SEEK`/`SEEKOP` в `PPIO.MAC` (подробно в шапке `SEEKOP`); корень задаётся словом `L0000/2 ! 100000`, в `SEEKOP` до дерева проверяются `?` (PRINT) и апостроф (REM). По коду `SEEK` слово принимается и при несовпадении в хвосте, если совпало не меньше символов, чем задано параметром (сокращение; на выполнении не проверялось). Вместо линейного перебора `OPRNAM`/`AOPNAM` (в 1988) компилятор ищет слово по префиксному дереву.

## Бейсик (ЦП)

### Происхождение кода (разметка по Бейсику Вильнюс 1988)

В модулях Бейсика (`MONIT`, `IO`, `COMP`, `TRAP`, `JMIN`, `JMP`, `DISK`, `GRAFUK`, `FLOATS`, `DT`, `GENUKD`) расставлены метки блоков (`x-origin.py`, сверка по тексту команд без комментариев, регистра и пробелов с `BASIC-UKNC-DSK-1988-NEW`; блок - от метки до следующей метки, длинные блоки делятся по внутренним меткам): `[1988=]` - без изменений (с указанием строк 1988), `[1988~N%]` - изменено (N% строк совпало, число строк в 1988 и здесь), `[НОВОЕ]` - аналога нет. В начале каждого модуля - сводка. `JEXT`, `PPIO` и `TABL` в 1988 отсутствуют (в `PPIO` найдены только `APUSH`/`APOP` из `JMP.MAC`). Запуск: `python x-origin.py` (показать), `python x-origin.py --write` (вставить), метки заменяются при повторном запуске. Разбор отличий вручную - в `x-origin-notes.txt` (строки `@МОДУЛЬ.MAC:БЛОК`), он попадает в метки блоков; сводка в начале модуля перечисляет и блоки 1988, которых в Турбо нет. Отличия разобраны во всех модулях Бейсик-части, найденных в 1988 (`IO`, `MONIT`, `TRAP`, `JMIN`, `JMP`, `COMP`, `GRAFUK`, `FLOATS`, `DISK`); выводы сделаны сравнением текста, на выполнении не проверялись. `JEXT` (новый) размечен по блокам с указанием, что взято из 1988 (`FILNAM`/`$BIN`, `SIGNAL`, стек кадров `CIKL`), остальное - обращения к драйверу `TGRAPH`; `PPIO` размечен по блокам с указанием, что в 1988 стояло на месте каждого (монитор, `.CSIGEN`, чтение каталога, `TRAP 113`); `TABL` - генерируемый файл, без разметки по блокам. «Без изменений» не учитывает комментарии; строки 1988 под условной компиляцией, удалённые в Турбо, дают метку «изменено».

### `GENUKD.MAC`

Настройки условной компиляции - тот же файл, что в 1988 (`MASINA=UK`, `GRAFTYP=UK`, `PRC=FIS`, `MEMTYP=RAM`...). Отличие: идентификатор `.TITLE TBASIC`, `.IDENT /V01.95/`. `FFUN` определяется по `SNG`/`PRC`.

### `DT.MAC` - блок системных переменных (аналог `DAT.MAC` 1988)

Прокомментирован (шапка, коды дисковых операций и ошибок, неописанные переменные; авторские комментарии 1988 сохранены; часть дисковых счётчиков `INCNMB`, `BLKCNT`, `BUFCNT`, `ENDFLG` используется в основном в закомментированном коде `DISK.MAC`; не найдены в других модулях `HS`, `FR.`, `WSCCA`, `EXTFLG`, `KOM2P`, `SCRL`, `LL`, `MIDLE`, `ENDBUF`, `CURS`, `$SCRT`). Определяет макросы `.DW`/`.DB` (последовательное выделение смещений от `STACK = 1000`) и перечисляет все глобальные переменные Бейсика. От 1988 сохранён практически весь список (`LYGIS`, `TXEND`, `STRREG`..`FREBEG`, `ENDCOD`, `CIKL`, `LIMIT`, `LENT`, `TABTOP`, `FCB`, `HIMEM`, `TRFLAG`, `AUTOON`, `III`/`RNDSAV`, `USRTAB`, `SAVJMP`, `PFACT`, `TMPSP`...). Новое: переменные драйвера Турбо-графики (`RADR`, `RWIDTH`, `HOTKB`, `KBBIT`, `DRVREG`, `CODP`, `PASSW`, `WORK0..3`, `Sc12Id`, `ApdId`, `EXTFLG`), переменные дискового обмена с IDE (`PCOD`, `PREADY`, `PNAME`, `PBLOCK`, `PLEN`, `PERR`), запрос следующей строки при компиляции (`CPCD`, `EXTSP`), `SAV474`, `DbgId`, `TboId`, `MemAvl`, `CURTAB`, имя файла (`DEVNAM`/`FLENAM`/`EXTNAM`), `ApdBuf`. Конец области - `BEND`/`EndCPV` (файловый буфер 400, буфер ввода `BUF` 200, `BUFOUT` 14).

### `MONIT.MAC`

Прокомментирован. Короткий (около 390 строк без меток против 1761 в 1988): остались старт и служебные подпрограммы. Нет цикла «Ok», команд `NEW`/`LIST`/`RENUM`/`DELETE`/`RUN`, `EDIT`/`AUTO`, отладки `STEP`/`TRON`/`SEPAP`, печати ошибок `MSTYPE` - всё это теперь в IDE. Остались: `START` (сохранение низкой памяти 0-13, векторов `AVPK` и FIS в `SAUG`, `.SETTOP`, начальные значения `AUINC`, `CURLIN`, `III`/`RNDSAV`, `USRTAB`, `APRL`, пустая программа `CLRTXT`, `MIDM`, `IOINI`), `INIT` (перезапуск: в ячейке 0 лежит `JMP @#INIT`), `SETW` (вектора `BREAKW`, `TRAPW`, `AVPK`, `ILCODW`, `FLOATW`; вектор, перехваченный прежней программой через `ON`, снимает `RSTVCT`), `ADDRMN` (выход в RT-11), `FERRI` (ошибки FIS), `CLRBUF`/`CLRTXT`/`CLRCOD`/`STRMEM` (память), `WRESET` (откат векторов `ON...GOSUB`), `IUNPCK`/`ISGUNP` (целое в десятичный текст: деление на 10 вычитанием сдвинутого делителя; в `ISGUNP` впереди знак или пробел). `BREAK`/`HALT`/`ENDPRG` не печатают сообщение, а кончают запрос IDE: `PERR` = 254 («СТОП»), 255, 0 и `CPEND` (`TRAP N` кладёт в `PERR` свой номер ошибки). В конце `SETW` ЦП посылает ПП в канал `176674`/`176676` указатель на блок `14000, 32, Es` - тот же вид, что `Mp.Exe` в `IDE.MAC` (команда запуска процедуры ПП по адресу `Es`, не проверено), и ждёт запросов (`BR .`). Не используются: `CHIMEM`, `RTIO`, `LC1`, `Switch`. В `ADDRMN` слово `10024` (восьм.) - команда F20 драйвера графики (снять) с паролем 20 в старшем байте.

### `IO.MAC`

Прокомментирован. Сокращён (около 350 строк без меток против 1302 в 1988): экранного редактора `IVEIL`, ESC-обработки и `NOSTOP`/`STOPEN` нет. Консоль ЦП (регистры `177560`-`177566`) обслуживает ПП: `ISV` выводит символ через `177564`/`177566` и следит за режимом РУС/ЛАТ (коды 16/17, признак `RusLat` = 200), клавиатура приходит прерыванием `IVS` в кольцевую очередь `FIRST`/`LAST` (`IV`/`NIM` читают; в режиме РУС буквы получают старший бит, DEL становится 377). `ISVEIL` печатает строку (код конца в старшем байте `R2`), на время вывода переключая терминал в ЛАТ. `INBF0` - ввод строки для `INPUT` с эхо и забоем. `ISVTO`/`ISVETO` направляют вывод по `IODEV` (0 - экран, > 0 - файл через `FILOUT`/`COPOUT`, < 0 - принтер через `LPISV`), `LOK` - `ESC Y`, `GetTXY` - положение курсора ПП командой 23. драйвера `TGRAPH` (`F23`: поля +16 и +20 структуры `@#23150`), `CURON`/`CUROFF` - цвет курсора 7 / 0 командой 19. (`F19`).

### `COMP.MAC`

Компилятор: структура та же, что в 1988 (подпрограммы `LET`, `IF`, `FOR`, `PRINT`, ...). Отличия: (1) нет таблиц `OPRNAM`/`AOPNAM` - ключевые слова ищутся по деревьям `TABL.MAC`; `AOPSUB` перечисляет подпрограммы компиляции в порядке номеров `TAB.TXT`; (2) убраны команды монитора `NEW`/`AUTO`/`LIST`/`DELETE`/`LLIST`/`RENUM`/`CONT`/`RUN`/`ADDRMN`, `CSAVE`/`SAVE`/`LOAD`/`MERGE`/`FIND`, `TRON`, `$COD`; (3) добавлены `REPEAT`/`UNTIL`/`WHILE`/`WEND`, `GET`/`PUT`, `PALETTE`, `SOUND`/`FSOUND`/`NOSOUND`, `PAGE`, `DELAY`, `FPUT`/`FGET`/`FSAVE`/`FLOAD`/`CLOAD`, `SMODE`, `DEFINT`/`DEFSNG`/`DEFSTR` (`DEFTYP`), `WIDTH` (заглушка `JMP REM`; `TRAP` и `SCREEN` были и в 1988), `_`-операторы (быстрый доступ к файлам), `OPEN ... FOR APPEND`; (4) ссылки на строки (`TO`/`TO1`) разрешаются по таблице меток `LABTOP` (`TSTLAB` в `PPIO.MAC`) вместо цепочки в служебном слове строки (1988); (5) `INSCMP` (в `PPIO.MAC`) - вход компиляции блока операторов; `REM` теперь сам пропускает остаток строки.

### `TRAP.MAC`

Библиотека `TRAP 100`-`130` почти без изменений (96% общих строк с 1988). Отличия: распознавание ключевых слов функций через `SEEK` и `F0000`; нет таблицы `FUN`; в `TRAP::` проверка границ стека (`CMP SP,#502`) и ошибки не печатаются здесь, а передаются в IDE (`MOV R5,PERR`; `JMP CPEND`); добавлена ветка определения типа по `APRL`.

### `JMIN.MAC`, `JMP.MAC`

Ядро шитого кода почти без изменений (96-97% общих строк). Добавлены (в `JMIN`) `GetTXY` в операторах позиционирования (`LOCATE`, `TAB`, `POS`), убраны `MFPS`/`MTPS`/`NOSTOP`/`STOPEN` (отложенное STOP-прерывание отсутствует), `NEWLIN`/`JCLS` учитывают `IODEV`. В `JMP`: `$CONST` теперь пропускает строковые константы по длине вместо копирования (`$CONST::TST (R4)+`...), `OpApd` (`OPEN ... APPEND`, `ApdId`), нет `$FIND`, `$COD`, `ISVARD`/`TESTR`/`BLOCK0`/`BLOCKN` (файлы кода и «магнитной ленты»), `FILTYP` расширен (`FNT`), `$USR`, `ONTRG$`/`TRPOF$`/`RSTVCT`/`TSTVCT` сохранены без обработки STOP.

### `JEXT.MAC`

Прокомментирован. Новый модуль «расширенные операторы» (Герасимов, 22.01.1995): обработчики шитого кода, компилируемые подпрограммами `COMP.MAC`. `D$Num` - `NUMBER` = номер строки (его вставляет `PCOMP`). Циклы: `$REPT`/`$UNTIL` (кадр в стеке кадров `CIKL`: адрес тела и маркер `125252`) и `$WHILE`/`$WEND` (операнд `WHILE` при компиляции - начало условия; при первом выполнении ищется свой `WEND` с учётом вложенности, после чего операнд `WEND` - начало условия, операнд `WHILE` - выход). Образы: `$GET` (на стеке адрес, Y2, X2, Y1, X1; образ - ширина и высота в точках, затем по октетам три байта плоскостей 0, 1, 2; плоскость 0 доступна только ПП и читается F24 параллельно, плоскости 1 и 2 ЦП читает окном `176640`/`176642`) и `$PUT` (режимы 0-3: замена, XOR, OR, сброс; края байтов - `Bic1`/`Bic2`, плоскость 0 пишет ПП командой F25, остальные - `MovPut`/`XorPut`/`BisPut`/`BicPut`; `Shift`/`Shift1` - сдвиг по X mod 8). Прочее: `$PALET` (F5), `$Delay` (n * 50. тиков, счёт прерываний таймера 100), `.$Read`/`.$Write`/`.$Purge`/`.$Close`/`.$Open`/`.$Creat` (EMT RT-11, ошибки не проверяются, `GtFNam` - разбор имени), `$Fsave`/`$Fload` (шрифт в файл `.FNT`: признак `FN`, первый код, число образов, по 11 байт, через F21/F22), `$Cload` (`LdObj` и запуск), `$SMode` (F2), `$Sound`/`$Fsoun`/`$NSoun`/`$Page` (F0, F15, F16, F18), `$FPut`/`$FGet` (F21, F22). Не выяснено: ошибка 50 в `$Cload` (в `ERMSG.MAC` её нет).

### `DISK.MAC`

Дисковый драйвер под RT-11: основа 1988 (`RT11`, `MREND1`, `OPWR`), но убрано чтение каталога (`F4$`-`F13$`, `RASC`, `LENT`, `DAL1`), добавлено дописывание в конец файла (`FilApd`, `ApdCpy`, `ApdBuf`, `ApdId`). Общих строк 77% по отношению к 1988.

### `PPIO.MAC`

Новый модуль («unit handle IO operations of IDE»), прокомментирован. Протокол запроса IDE -> Бейсик (шапка модуля, `$$DSCL` в `IDE.MAC`): ПП окном `177010`/`177014` заносит в память ЦП блок из 7 слов, начиная с `PCOD` (байт `PCOD` - код запроса, байт `PREADY` = 377 «занят», `PNAME` - имя файла в RAD50, `PBLOCK`, `PLEN`, `PERR`), подставляет в вектор 24 ЦП адрес из вектора 104 (там `INT104`, его ставит `IOINI`, слово 26 = 0) и прерывает ЦП через `177716`. `INT104` сбрасывает стек, вызывает `VRES` и по таблице `JTAB` переходит на процедуру; она заканчивается `JMP CPEND`: `PREADY := 0`, ЦП ждёт (`BR .`). ПП ждёт `PREADY = 0` и читает `PERR` (0 - успех, 1 - ошибка RT-11, иначе номер ошибки Бейсика из `ERMSG.MAC`, 254 - «СТОП»).

Коды запросов (десятичные): 0 `POPEN`, 1 `PCLOSE`, 2 `PREAD`, 3 `PCREAT`, 4 `PWRITE` (EMT RT-11 по каналу 13), 5/6 `PSWAP`/`PUNSWP` (область `TEXT` в файл подкачки `DK:TBASIC.SWP` и обратно), 7 `PCOMP`, 8 `PRUN`, 9-11 `PCSIOP`/`PCSICR`/`PCSCRN` (разбор имени `.CSISPC` и открыть/создать/создать с резервной копией `*.BAK`), 12 `PGETFT` (список файлов по маске, каталог читается с блока 6), 13 `PTEST` (разбор и достройка имени `dev:name.ext`), 14 `PEXIT`, 15 `PPRINT` (вычисление: присваивания из `BUF+60.` и вывод выражения из `BUF`), 16 `PPrgRs` (сброс), 17 `PLdTbo`.

Компиляция (`PCOMP`): ЦП берёт строки исходного текста у ПП по слову `CPCD` (пишет `10001`, ждёт ответа; `Comp.H` в `IDE.MAC` кладёт строку в `BUF`; `^Z` - конец), компилирует через `INSCMP` (метки - в таблице `LABTOP`, запись: состояние, адрес кода, номер строки; состояние <> 0 - неразрешённая ссылка), в конце пишет `ENDPRG` и создаёт `.TBO`. Формат `.TBO` описан в шапке: блок 0 - слово 0 = `TEXT`, слово 1 = размер, слово 2 = «BO», 128 слов системных переменных с адреса `STACK`; с блока 1 - код и таблицы `LENT..TABTOP`. `LdObj` проверяет слово 0 и `WHIMEM`. `VRES` не возвращает RT-11, а ставит вектора Бейсика: таймер (100) на `RTI`, клавиатура на `IVS`.

Не используются в исходниках Turbo: `UBRUK`, `APUSH`/`APOP` (порядок снятия не обратный постановке). Параметр `SEEK` по коду - минимальное число совпавших символов для сокращения слова (на выполнении не проверялось). Открыто: куда идёт вывод `PPRINT` (`LPRINT`, `IODEV = -1`), формат `.CSISPC`-области проверен только по RT-11.

### `GRAFUK.MAC`

Графический модуль, переделан под драйвер Турбо-графики («для работы с драйвером x-graph»): вместо ESC-последовательностей терминала (1988) каждая операция графики - это код в `CODP`, параметры в `WORK0..3`, и вызов `PPEXE` (записывает пароль `20` в `PASSW`, драйвер в ПП сбрасывает его по исполнении). Есть `TsSc12` - пересчёт Y для режима IBM 640x480 (`Sc12Id`). Дуги и круги (`$ARC`, оператор `CIRCLE`) остались, как в `GRAFUK.MAC` 1988 (отдельный `GRCIRC.MAC` 1988 в сборку не входил); в драйвере `TGRAPH` процедуры для кругов нет, значит они рисуются обычными командами точки. Убрано программирование функциональных клавиш (`$KEY`), `GCOM`/`GINT`/`ESCLN`; добавлены режим экрана 12 (`SMODE`, `SCRRES`), `GXYR`.

### `FLOATS.MAC`

Практически без изменений от 1988 (94-96%): формат чисел, `PACK`/`UNPCK`, арифметика, функции, `RAN`, `STAND`. Отличия формальные (`@SP` вместо `(SP)`, `RTS PC`, десятичные константы записаны восьмеричными); реальное изменение одно - датчик `RND` (`RAN`, `RANXOR`, `GETRAN`: сдвиговый регистр с обратной связью подмешивается к случайному числу). `MOV #16,R5` -> `#20` находится не здесь, а в `BIN$` (`JMP.MAC`): 16. цифр вместо 14., возможное исправление ошибки 1988.

### `FONT.MAC`

Прокомментирован. Входит в `Ide.Sav` (не в Бейсик). Секция `DATA`, метка `MASSIM::` - 9 знаков по 11 байт (строк развёртки), которые `SwpFnt` (`IDE.MAC`) подставляет в таблицу шрифта ПП (`14542`, 9 указателей) вместо прежних, `RSTFNT` возвращает. По использованию в `WINDOW.MAC` и `EDIT.MAC` это знаки 200-210 (восьм.): 200 стрелка вверх, 201 вниз, 202 влево, 203 вправо, 204 дорожка полосы прокрутки, 205 точка переключателя, 206 бегунок, 207 и 210 - тени справа и снизу. Таблица указателей шрифта ПЗУ - `14142` (слово на код, 256 слов), слот кода 200 - `14542`, поэтому слоты соответствуют кодам 200-210 (проверено по `RAM.LST`).

## Турбо-графика (ПП)

### `TGRAPH.MAC`

Прокомментирован. Резидентный драйвер графики, звука и клавиатуры ПП (Герасимов, 17.11.94; линкуется последним в `Ide.Sav`). Установка: `TGINST` (в ЦП) шлёт ПП по каналу `176674`/`176676` блоки `MP.PUT` (записать `Inst` в ОЗУ ПП с адреса 1000) и `MP.EXE` (запустить); `Inst` при отключённом ПЗУ (`177054`) копирует `TGPut..TGEnd` из памяти ЦП в ОЗУ ПП с `170400`. `TGPut` ставит вектора ПП: 100 (таймер, мелодия), 300 (клавиатура, `INT300`: `HOTKB`, маска `KBBIT`), ячейку `7126` (процесс `INT330`), `13172` (`CLS`), `14` (`F.RUN`).

Интерфейс с ЦП - переменные ЦП у `DRVREG` (`DT.MAC`): `RADR`, `RWIDTH`, `HOTKB`, `KBBIT`, статус (бит 7: 1 - выполнено), `CODP` (код процедуры), `PASSW` (пароль 20 восьм.; `INT330` выполняет команду только при нём и обнуляет его), `WORK0..WORK3` (аргументы `R1..R4` и результат). ЦП вызывает `PPEXE` (`GRAFUK.MAC`). Процедуры по `DTAB`: F0 звук, F1 сдвиг экрана, F2 режим вывода (замена/XOR), F3-F5 палитра, F6 точка, F7 цвет вектора, F8 цвета текста, F9 указатель, F10 линия (Брезенхем; вертикальная и горизонтальная отдельно, XOR - `XrLin`), F11 закрашенный прямоугольник, F12 цвет точки, F13 читать указатель, F14 заливка (процедура ПЗУ `151714`), F15/F16 очередь нот / стоп, F17 режим 80/40 символов, F18 страницы, F19 цвет курсора, F20 снять драйвер, F21/F22 образ символа, F23 положение курсора, F24 читать плоскость 0, F25 вывести образ (`MovPut`/`XorPut`/`BisPut`/`BicPut`). Подтверждено со стороны ЦП: `GetTXY` (`IO.MAC`) использует F23, `CURON`/`CUROFF` - F19.

Сверка с листингами ПЗУ: `7126` - ячейка запуска фиктивного (10-го) процесса диспетчера ПЗУ (`174164` - цикл по флагам `7060`..., ненулевая ячейка запуска - `JMP` с обнулением, `174222` - стандартная фиктивная процедура), поэтому `INT330` в конце снова ставит себя в `7126` и передаёт управление `OLD330` (по умолчанию `174164`). `INT100` обнуляет `7046` и сбрасывает биты 8-11 `177716`: иначе ПЗУ по истечении длительности сигнала сбросило бы `17600`, включая бит 7 динамика, которым звучит `INT304`. ПЗУ на нажатие клавиши даёт щелчок (бит 7 `177716`, `7046` = 2), на STOP очищает буферы клавиатуры и ставит HALT ЦП (бит 20 `177716`); `INT300` делает вместо этого только флаг `@#16`. `177026` - регистр запрета плоскостей (бит 0 - режим 4 цветов; `F3`-`F5`, `F12`, `F24`, `F25` его учитывают). `13172` - слово таблицы обработчиков управляющих кодов ПЗУ (`Ctrl-L`, CLS; `RstVct` возвращает `113236`), вектор `14` (BPT) указывает на `F.RUN`. В `F17`/`F18`: `22744` - режим экрана (ТВ `+66`), `22660`/`22662`/`22666` - начало видеопамяти, знаков в строке и длина видеострок (ТВ `+2`, `+4`, `+10`), `23432` - адрес 264-й видеостроки (`2500 + 4*264 - 4 = 4534`), страница 1 - экран установки (ТВ `22754`), `23412` - ширина экрана в точках (рабочая область ПЗУ). Открыто: что именно делает `Esc UB` (`151714`) и смысл значения 264. в `22754+16`.

Возможные ошибки оригинала: при неверном коде процедуры `F.RUN` уходит на `EX`, который снимает со стека адрес возврата вместо `R1`; при снятии маски клавиш в `INT300` сравнивается младшая тетрада байта `KTAB`. Не выяснено: кто вызывает `TGPut` после копирования `Inst`, что именно делает `Esc UB` (процедура ПЗУ `151714`), смысл значения 264. в `22754+16`.

## IDE (ПП)

### `IDE.MAC` - главный модуль

Прокомментирован. Секции: `Install` (ЦП) - `IdeIni`: имя устройства запуска, запрос памяти у ПП (`Mp.All`), релокация резидента по таблице `Rtab` (макрос `Rel`), запись в ПП (`Mp.Put`), `TGINST`; `Locked`/`System` (резидент в ПП). `Begin`: вектора 100, 34, 300, палитры, шрифт (`SwpFnt`: 9 образов `MASSIM`), клавиатура (`ReKey`: у пяти таблиц 16 клавиш по `NKey` получают коды 200-217: стрелки, F1-F10, Del, Ins), экран (`ReScr`), файл установок `DK:TURBO.DSC` (`$LdSk`), текст (`$LoadF`), редактор (`$Edit`). `CmAppl` вызывается диспетчером процессов (`TRAP 0`): `Comp.H` отдаёт ЦП очередную строку исходного текста по запросу `CPCD` (10001; после последней - `^Z`), раз в 16 строк обновляет окно компиляции; на Break (флаг `@#16`) при компиляции или выполнении прерывает ЦП по его вектору 4 (через вектор 24), иначе кладёт F10 в очередь клавиш. Текст лежит в ОЗУ ПП 100000-170000 под ПЗУ (`PZUOff`/`PZUOn`), файлы идут порциями по 5120. слов через область `TEXT` ЦП (`Bbuf`..`kBuf`).

`$$DSCL` - запрос к ЦП (блок `FFFF`, 7 слов, в память ЦП с `PCOD`; вызов `INT104` через вектор 24; ожидание `PREADY = 0`; `FERR` = `PERR`), `C1CALL` - то же с повтором по Enter и отказом по Esc, `$NCopy` - имя в `BUF` ЦП и достройка (`PTEST`, код 13). `$LoadF`: коды 16/17 в файле переключают РУС/ЛАТ (бит 7 букв), Tab - пробелы до кратного 8, строка до 253. символов; `$SaveF`: строки с CR LF, резервная копия BAK по `ESW` (бит 1). `$DRPRT`/`$DREXE` - диалог выбора файла: список из `PGETFT` (записи по 16 байт), две колонки по 8 имён, полоса `ESLDIR`, клавиши по `DIRJMP`. `INT100` - мигание курсора IDE (10. тиков, форма по `ESW`). Системные ячейки ПП и процедуры ПЗУ (`7046`, `7134`, `22656`, `23150`-`23166`, `100242`, `104054`, `105306`) выяснены по листингам ПЗУ (раздел «Системные ячейки ПП»); не выяснено: формат записей списка видеострок (`2456`-`2466`), расшифровка «ИСУ» (`22552`).

### `WINDOW.MAC` - оконная система

Автор модуля - «Саша Акулин» (так подписан файл в исходном заголовке), не Герасимов. Модуль полностью прокомментирован: в шапке файла - формат описания окна и элементов диалога, рабочие переменные, обращения к оборудованию ПП.

Окна вдохновлены Turbo Vision (диалоги `DIALOG`, рамки, тень `SHADOW`, кнопки с тенью, флажки, переключатели, строки ввода, полосы прокрутки, горячие клавиши), но устройство процедурное: дерева видов, владельцев и очереди событий нет. Окно - статическое описание в `IDDAT.MAC`/`IDDAT2.MAC` (макросы `.WIND`, `.BUTON`, `.EDIT`, `.USER`, `.ENDS`), код только рисует его и крутит модальный цикл ввода: клавиша -> `KEYJMP` -> таблица переходов (`UKJMP`, `EXJMP`, `BRJMP`, `TRJMP`, `MEJMP` в `IDDAT*.MAC`). Строки рамок собираются в `TTBUF` и уходят в терминал ПП через `TRAP 0`; координаты и вид курсора берутся из структур системы ПП (`@#23150`, `@#2476`).

Состав:
- цвет и курсор: `$COLOR`/`RSTCOL`, `$LOCAT`/`$$LC`/`$WLOC`, `$CURON`/`$CUROF`/`$CHIDE`, `$INV` (подсветка прямоугольника);
- верхнее меню: `$UPMEN`, `$UR`/`$UL`/`$UE`/`$UES`;
- меню-окно: `$WIND` (рамка, пункты, разделители, подсказки клавиш), `$EXE` (выбор пункта), `$EMPT`, `$SHDW` (тень);
- диалог: `$INBAR` (рамка, тело), `$$BRPR`/`$$TSPR` (рисование элементов), `$EXEB`/`$BGRS` (цикл), `$TREX`/`$TRBG` (списки), `$EDEX` (строка ввода), `$NOPR`/`$ENTER` (отказ, Enter);
- сервис: `$PUSH`/`$POP`, `$KJMP` (переход по таблице клавиш через `RETURN`), `$SAVE`/`$CLOSE` (копия фона в видеопамяти), `$GETY`, `$PRTZ`/`PR`, `SCRBLP`/`SCRBLM` (полосы прокрутки).

По листингам ПЗУ (см. «Системные ячейки ПП») выяснено: `177016` - регистр кода цвета точки, `177020`/`177022` - кода цвета фона (из ТВ `+40`), `@#7066` - счётчик символов в буфере вывода, `@#7214` - адрес текущей таблицы раскладки клавиатуры, `@#22656+44` - цвет фона в ТВ. Открыто: назначение `177024`; в какой памяти лежит «прежнее значение» поля ввода; смысл подмены `COM` на `SWAB` в `$INV`; в `RSTCOL` цвет пишется в `177010`, а не в `177016` (возможная ошибка автора).

### `EDIT.MAC` - текстовый редактор

Прокомментирован (код приведён к табуляции вместо пробелов, как в остальных файлах). Окно - 20 строк (`ED.Y`) и 78 столбцов (`ED.X`, горизонтальный сдвиг `ROL.HD` - «рулон»); первая видимая строка - `SL.PTR` (номер `ROL.GD`), длины видимых строк - `SL.LEN`. Текст лежит в ОЗУ ПП (`UP.PTR..DN.PTR`) строками с нулём на конце; текущая строка копируется в `LBUF` (256 байт, добита пробелами) - `$LCOP` - и возвращается в текст через `$LPUT`/`$LPALL`/`$LPUTN`: при смене длины текст сдвигается на разницу, ПЗУ отключается (`PZUOff`). Курсор: `LB.PTR` в `LBUF`, `MX.PTR` - запомненный столбец. Слово `ESW`: 1 - резервная копия, 2 - вставка, 4 - автоотступ при Enter, 10 - при забое, 20 - перманентные блоки, 40 - большой курсор, 100 - поиск под курсором, 200 - длинные строки, 400 - замена пробелов (названия - из окна «Редактор», `IDDAT2.MAC`; 20 и 40 не изучены).

Главный цикл `$EDIT` читает клавишу и переходит по `EDJMP` (в стек кладётся адрес `$RST`, поэтому обработчики кончаются `RETURN`). Перемещения идут по таблицам `L.REG`/`R.REG`/`U.REG`/`D.REG` по модификатору (`R5`): обычный, Shift, Ctrl, GRAF, Alt; `$EDS` - символ (буквы по `RSLT`), `FKJMP` - F1-F10 (таблица `TFK`), `ALJMP` - Alt-буква (меню; Alt-X - выход). Есть слово влево/вправо (`$CR.LS`/`$CR.RS` по карте `BITMAP`: бит 1 - символ слова, 0 - разделитель; комментарий автора называет её картой разделителей), страница, начало и конец текста, Ctrl-Y/N/W, поиск `$FND` (`FSW1` - назад, `FSW3` - откуда, `FSW4` - регистр). Прокрутка окна (`$RHD`, `ROLDN`, `ROLUP`) и индикатор положения (`$C.PRT`) работают с системными таблицами строк ПП (ячейки 2626, 4462, 4464 - по расчёту смещений слова ссылок списка видеострок 2500-4666, перестановкой ссылок окно прокручивается; 22656 и 22674 - поля +0 и +16 таблицы видеопараметров экрана).

### `UPEXEC.MAC` - функции верхнего меню

Прокомментирован (код приведён к табуляции). Функции меню `F01`..`F95` вызываются по таблицам `IDDAT.MAC`: `F01` About; `F02`/`F03` Transfer (`DK:PAINT.TBO`, `DK:EDITFT.TBO`: при режиме 8 цветов текст уходит в своп-файл `DK:TB0000.SWP`, `CpCall #17.` - `PLdTbo`, затем `Exec`); `F11` Open (`$OpF`), `F12` New, `F13` Save, `F14` Save as (`$SvF`), `F15` Save all (`F13` + `F75`), `F19` Exit (`TstAsv`, окно `TsChD`, `Qui`: восстановление экрана, шрифта, палитр, клавиатуры, векторов 100/34/300, освобождение памяти, команда 14. ЦП - `PEXIT`); `F31` Find, `F33`/`$SRC` Search again, `F34` Go to line, `F35` Show last error; `F41` Run (`TstAsv`, компиляция `F511`, `EXEC`: палитра Бейсика, `NmKey`, `Bs.Exe`, затем `ReKey`, сообщение об ошибке `EbStr`/окно `DBGD`), `F45` Program reset (`CpCall #16.` - `PPrgRs`), `F51` Compile (`CpCall #7` - `PCOMP`, `DbgID` из `PSW3`/`PSW4`, результат в `CM.ERN`/`CM.ERL`), `F61` Evaluate/Modify (`$EVLT`: `CpCall #15.` - `PPRINT` с перехватом вывода по вектору 330 - `TTGET`); `F741`/`F742`/`F744` настройки и палитры (`$SPMN`/`$SPCL`), `F75` Save desktop (`DK:TURBO.DSC`, `DscTop..EndPP`), `F81` Refresh, `F91`/`F95` справка. `PpCp` - запись слов из ПП в ОЗУ ЦП через окно `177010`/`177014`. `VLook`/`VUnlook` - сохранение/загрузка текста (`100000..DN.PTR`) в `DK:TB0000.SWP` порциями по 10000 слов; `TstAsv` - автозапись (`PSW2`: бит 1 - текст, бит 2 - установки). Бит 100 `ESW` («Поиск под курсором») в `F31` подставляет в поле поиска слово под курсором: `FB.PTR+5` - флаги поля ввода `.EDIT` (бит 1 - взять прежнее значение, бит 2 - строка с нулём на конце); `F71` собирается только в версии Beta.

### `MEMORY.MAC` - диспетчер памяти ПП

Прокомментирован. Секция `Locked`. `PZUOff`/`PZUOn` (отключение и подключение ПЗУ ПП через `StatMem` = `177054`, биты 360; пара также запрещает и безусловно разрешает прерывания), `INT34` (обработчик TRAP: номер из команды `TRAP N`; `TRAP 0` - диспетчер процессов ПЗУ (`7056`, `7060-7126`, см. «Системные ячейки ПП»): `CmAppl`, адрес возврата текущего процесса (запись по ячейке 7056, смещение 22) запоминается и управление уходит процессу из ячейки 7126 без проверки на 0; иначе `JMP @160160(R0)`), `TgLoad`/`TgUnLo`/`TgSwap` (обмен образа драйвера графики в ПП (`mSwap`, длина `TgEnd-TgPut`) с областью окна `177010`/`177012` с адреса `HiText+400`; вход `mSwap` - установка, `mSwap+2` - снятие), `Bs.Exe` (драйвер + запрос ЦП 10 (восьм.) = `PRUN` + выгрузка), `Int300` (клавиатура редактора: кольцо 8 байт по указателю 7200, STOP - флаг On Break в ячейке 16; начало совпадает с `INT300` из `TGRAPH.MAC`). Не выяснено: согласование адреса `170400` в `TgSwap` (окно) и в `Inst` (`TGRAPH.MAC`, ОЗУ ПП).

### `VAR.MAC`

Прокомментирован. Переменные IDE (раздел `Variable` резидента ПП, макрос `.DW имя [байт]`): данные верхнего меню (`UPWRK`, `WPNT`, `ENTFLG`), оконной системы (`CL.X`...`W4`, `WA`, `WBUF`, `WAREA`, `BAREA`, `B.PTR`, `JMPADR`, `KEYCOD`), компилятора (`CM.PTR`, `CM.NUM`, `CM.FLG`, `CM.ERN`, `CM.ERL`, `RN.FLG`, `TrsFlg`, `RWait`), палитры (`SYSPL`, `IDEPL`, `BASPL`), буфера обмена с ЦП (`BBUF`, `kBUF`), помощи (`nHelp`, `LhPtr`). С метки `DSCTOP` до `ENDPP` лежит «рабочий стол»: `F75` записывает эту область в `DK:TURBO.DSC`, `$LdSk` читает обратно - редактор (`ED.X`, `ED.Y`, `LB.PTR`, `ROL.HD`, `ROL.GD`, `UP.PTR`, `DN.PTR`, `SL.PTR`, `EFNAM`, `MX.LIN`, `NONMID`, `ChngID`), палитры `PLG1`-`PLG4`, слова опций `ESW`, `CSW1`-`CSW3`, `FSW1`-`FSW4`, `PSW1`-`PSW4`, образец поиска `FDBUF`. В других модулях не найдены: `CopStm`, `HLLN`, `SWPFLG`, `SBX`, `SBY`. Смысл пометки `;!` у автора не выяснен.

### `IDDAT.MAC` - меню, таблицы клавиш, сообщения

Прокомментирован. Верхнее меню `MAIN` (адрес строки `MAINM`, цвет, номер последнего пункта, десятичные смещения пунктов в строке, адреса окон `TOP`, `FILE`, `SEARCH`, `COMP`, `OPTI`, `HELP`); окно-меню - `.WIND MENU,X,Y,ширина,число пунктов,цвета`, за ним адреса обработчиков (`F01`..`F95` из `UPEXEC.MAC`, `O2HLP`..`O5HLP` из `HELP.MAC`). Коды в текстах пунктов: 1 - подсказка клавиши (затем модификатор 4 Ctrl, 5 Shift, 6 Alt и текст клавиши), 2 - разделитель перед пунктом, 3 - многоточие. `AKTAB` - пять таблиц раскладки клавиатуры ПП (ПЗУ: основной регистр, нижний, УПР, ГРАФ, ФИКС; в IDE - обычный, Shift, Ctrl, GRAF, Alt), `NKEY` - смещения 16 переназначаемых клавиш, `UKJMP`/`EXJMP` - таблицы `KEYJMP` верхнего и выпадающего меню, `ESLHOR`/`ESLVER` - полосы прокрутки редактора (максимум 175 и 1000), `ETB`/`ETT` - названия модификаторов, `UL` - начало рамки диалога, далее сообщения (`DLL`/`DLS`/`DLD`, `DL2`, `IOERTX`, `SUCSTR`, `ERRSIR`, `EbStr` - ESC Y со строкой 23, `PRKEYT`, имена `SWNSC`, `DSFILE`, `NFILE`). Не выяснено: смысл `<13>` в конце строки меню; порядок элементов `NKEY` выведен по `ReKey`, не проверен по таблицам ПП.

### `IDDAT2.MAC` - окна и клавиши диалогов

Прокомментирован. Описания окон: слово - заголовок, `.WIND тип,X,Y,ширина,высота,цвета` (`DIALOG` - с вводом, `PRINT` - без ввода), слово - тело, элементы: `.BUTON` (бит 0 обработчика: 1 - подпрограмма, окно остаётся), `.EDIT` (флаги: бит 1 - взять прежнее значение, бит 2 - строка с нулём), `.USER`, группы значков (код 1 - `( )`, 2 - `[X]`: переменная, смещение подписи, пары X, Y, затем код следующего элемента), `.ENDS`. Окна: `ABOUT`, `PALETE`, `OPEND`, `SAVED`, `TsChD`, `HELPW`, `COMPD`, `DBGD`, `EDITD`, `COMPO` (только Beta), `FINDD`, `NOTI`, `GOLNM`, `PREFM`, `EVLMDD`. Опции: `ESW` (`EDITD`), `FSW1` вперёд/назад, `FSW3` сверху (0)/снизу (1)/от курсора (2), `FSW4` флажки РУС/ЛАТ (1), ВР/НР (2), Слово (4), `PSW1` 4/8 цветов, `PSW2` автозапись программы (1)/настроек (2), `PSW3` отладка включена (0)/выключена (1), `PSW4` объектный код в память (0)/файл (1). `FSW2` и бит 4 `FSW4` в коде не используются; кнопка «Заменить» в `OPEND` лишь закрывает окно. Таблицы клавиш `BRJMP`, `TRJMP`, `MEJMP`. Тексты - секция `Text` (заголовок: столбец и строка; тело: 0 - пустая строка, 1-77 - столбец и текст, 100+n - n пустых строк). Не выяснено: второй байт заголовка группы значков; у `ABOUT` и `DBGD` нет слова Enter после кода 0.

### `HELP.MAC` - контекстная помощь

Прокомментирован. Файл `Turbo.Hlp` (`HName`): заголовок - записи по 3 слова (блок, длина в словах, код темы), конец - код 0 (`HlRead`). Тема - текст строками с нулём на конце; байт 35 + 2 байта кода + текст + байт 36 - ссылка (`LGBut` строит таблицу ссылок строки, `TstInv`/`NamInv` подсвечивают ссылку под курсором, Enter открывает тему). Внутренние коды: `100200` - оглавление, `100201` - как пользоваться, `100202` - редактор; внешний номер `nHelp` переводит `NhConv`. Тема читается в ОЗУ ЦП (код 2, `BBUF`) и копируется в ОЗУ ПП за текстом программы (`TopPtr..EndPtr`, ПЗУ отключено). Окно - `ScOut`, полоса - `EslHlp`. Клавиши (`HtJmp`): стрелки, Esc (закрыть), Enter (перейти), F1 (помощь о помощи), Shift-F1 (оглавление), Alt-F1 (предыдущая тема по истории `LhPtr`, 6 байт на запись, `12200..12360`). `O3Hlp` - поиск темы по слову под курсором в оглавлении. Не выяснено: смысл ESC-кодов `240 67`/`277 240` в `Lcpy` (выделение ссылки), слово `$$$1` в `$Inv`, чтение позиции с адреса `120000` в `H.Prev` при пустой истории, подстановка устройства в `???:Turbo.Hlp`.

### `ERMSG.MAC`

Прокомментирован. Список `ERR.MS` в секции `Text`: запись - байт кода и текст с нулём на конце, конец - код 0 (`"?"` для неизвестных кодов). Коды 1-24 - как в Бейсике, 51-59 - файлы, 63 - компилятор, 254 - СТОП, 255 - прерывание 4 ЦП (кодов 12, 17, 20-22, 25-50 нет). `GETFMS` ищет сообщение по `R5` (сравнивается байт); `GETMSG` кладёт его по центру строки окна `DBMSG` (32 символа, длина больше 32 не проверяется), `GETMS1` формирует в `TTBUF` строку "код: текст". Опечатки в текстах оригинала ("Неопределеная", "длиная", "Повтроная") оставлены.

| Циклы | `FOR`/`NEXT` | + `REPEAT`/`UNTIL`, `WHILE`/`WEND` (`JEXT`) |
| Файлы | `DISK`, `FILES`, `SAVE`/`LOAD` | через ПП (`PPIO`), `.TBO`, `_`-операторы |
| Сохранение программы | текст/двоичный | `.TBO` (объект) + `.BAS` (текст в IDE) |

## Открытые вопросы

- Что делает блок `14000, 32, Es`, который ЦП шлёт ПП в конце `SETW`: по виду - команда запуска по адресу `Es` (как `Mp.Exe`), не проверено на ПП-стороне.
- Генератор `TABL.MAC` (в каталоге отсутствует); формат деревьев проверен по `TAB.TXT`/`TABF.TXT`.
- Параметр `SEEK` по коду - минимальное число совпавших символов для сокращения слова (проверить на выполнении); потребители блоков `PSWAP`/`PUNSWP` в IDE.
- Сборки Турбо в этом каталоге нет: изменения комментариев и меток проверены только сравнением кода без комментариев.
- `OutScr.Sav`; `177024`; формат записей списка видеострок (ячейки `2626`, `4462`, `4464` выведены только по расчёту смещений).
