# Файлы исходного кода Бейсик-Вильнюс для УКНЦ

Ниже приведён список файлов с кратким описанием их назначения. Все файлы являются частью интерпретатора/компилятора языка BASIC, разработанного в Вильнюсском вычислительном центре (ВЦКП ВГУ).
Здесь рассматривается версия Бейсика для учебных компьютеров "Электроника МС 0511" (УКНЦ).


## 1. `COMP.MAC`

**Назначение:** Компилятор (синтаксический анализатор) языка BASIC.

Преобразует исходный текст программы во внутренний промежуточный код (таблицы строк, связей и исполняемых операторов). Содержит таблицы ключевых слов (`OPRNAM`, `AOPNAM`), адреса подпрограмм компиляции для каждого оператора (`AOPSUB`), а также логику разбора строк, обработки операторов (`LET`, `IF`, `FOR`, `GOTO`, `PRINT` и др.), выделения массивов, работы с графическими примитивами (`CIRCLE`, `PAINT`, `DRAW`), файловыми операциями (`LOAD`, `SAVE`, `OPEN`, `CLOSE`) и системными командами (`NEW`, `LIST`, `RUN`, `CONT`).

Главный цикл компиляции `RUN`/`LRUN`/`COMPIL`/`ENDTXT`: `LRUN` инициализирует состояние компиляции, `COMPIL` построчно вызывает подпрограмму нужного оператора через `AOPSUB`, `ENDTXT` - эпилог (дописывает `ENDPRG`, переносит тексты `DATA`-строк в код, разрешает цепочку `RESTORE`-без-номера через `AUTOON`). Прямые и обратные ссылки `GOTO`/`GOSUB`/`RETURN`/`RESTORE`/`ON` на ещё не скомпилированные строки разрешаются через связный список, хранящийся прямо в служебном слове каждой строки (см. `TO`, `SETST`). Числовые литералы (включая `&B`/`&O`/`&H`) разбирает `CISLO`/`BOHPAP`/`CHEX`/`COCT`/`CBIN`, результат упаковывается через `PACK` (`FLOATS.MAC`).


## 2. `DAT.MAC`

**Назначение:** Блок глобальных системных переменных (область данных).

Содержит все переменные состояния интерпретатора: указатели на таблицы (`TABTOP`, `FCB`, `LENT`, `ENDCOD`), флаги (`LYGIS`, `ERRS`, `TRFLAG`, `AUTOON`), регистры для работы со строками (`STRREG`, `STRSIZ`, `FREBEG`), генератор случайных чисел (`III`, `RNDSAV`), графические переменные (`CRTGRP`, `GRPEN`, `GRPAP`), буферы (`BUF`, `BUFOUT`, `EBUF`) и др.


## 3. `DISK.MAC`
**Назначение:** Драйвер для работы с дисковыми файлами через систему RT-11.

Реализует низкоуровневые операции чтения/записи блоков, преобразование имён файлов в формат RT‑11 (радикс‑50), обработку каталога, поддержку текстовых и двоичных файлов (ASCII/бинарный режим). Содержит подпрограммы `RT11`, `MRD` (чтение), `MWR` (запись), `FILES` (вывод каталога), а также служебные процедуры `RASC` (преобразование радикс‑50 в ASCII) и `ASCRD`/`ASCWR` для работы с текстовыми файлами.


## 4. `FLOATS.MAC`

**Назначение:** Набор процедур для работы с числами с плавающей точкой (формат DEC float).

Включает:
- Преобразование строки в число (`PACK`) и числа в строку (`UNPCK`/`EGO`).
- Арифметические операции (`ADR`, `SUB`, `MLR`, `DVR`, `ABS`, `SGN`).
- Тригонометрические функции: `SIN`, `COS`, `TAN`, `ATAN`.
- Экспоненциальные функции: `EXP`, `LOG` (натуральный).
- Корень числа `SQR`.
- Преобразование целое ↔ float (`IR`, `RI`, `INT`, `SVD1`).
- Генератор случайных чисел (`RAN`).
- Возведение в степень (`ROTG`, `ROTI`).
- Константу π (`PI`).
- Процедуру вызова шитого кода (`STAND`) для последовательного вызова подпрограмм.


## 5. `GENUKC.MAC`

**Назначение:** Файл настройки для условной компиляции (версия для УКНЦ).

Определяет тип машины (`MASINA=UK`), тип графики (`GRAFTYP=UK`), наличие сети (`NETTYP=NO`), тип процессора (`PRC=FIS` – аппаратная плавающая арифметика), тип памяти (`MEMTYP=RAM`), а также макросы для эмуляции команд сопроцессора. Включается в начало многих модулей.


## 6. `GENUKD.MAC`

**Назначение:** Аналогичен `GENUKC.MAC` (дублирует настройки).
Содержит те же определения условной компиляции, что и `GENUKC.MAC`. Вероятно, использовался для разных целей или как резервная копия. В исходниках Бейсик‑Вильнюс обычно присутствует только один такой файл.


## 7. `GRAFUK.MAC`

**Назначение:** Графическая подсистема (общие процедуры).

Реализует инициализацию графического режима (`GRINIT`), вывод символов, управление курсором, установку цветов, рисование точек, линий, прямоугольников, заливку (`PAINT`), а также обработку команд `DRAW` (макроязык перемещений). Взаимодействует с графическим контроллером через регистры `GRPCSR`/`GRPDBR`. Содержит также подпрограммы `POINT`, `SET`, `LSET`, `RECSET`, `BOXSET`.


## 8. `GRCIRC.MAC`

**Назначение:** Расширенная графика – рисование окружностей, дуг и эллипсов.

Содержит процедуры `$ARC` (построение дуги/эллипса с учётом сжатия по осям и граничных углов), `ANG1`, `ANG2`, `ASPINT`, `ASPSNG` (вспомогательные для обработки параметров), а также внутренние подпрограммы `$P4SET`, `$SETCD`, `$QS*`, `$QT*` для симметричного вывода точек по квадрантам. Используется оператором `CIRCLE` языка BASIC.


## 9. `IO.MAC`

**Назначение:** Система ввода‑вывода (экран, клавиатура, принтер, файлы).

Управляет полноэкранным редактором (`IVEIL`, `INBF0`, `INBF1`), выводом символов и строк (`ISV`, `ISVEIL`), обработкой управляющих клавиш (курсор, вставка/удаление), прокруткой экрана, переключением режимов экрана (`SMODE`), а также поддерживает файловый ввод‑вывод через драйверы. Включает подпрограммы для работы с графическим режимом (`SETCRT`, `CSCR`, `RSCR`) и обработку прерываний клавиатуры.


## 10. `JMIN.MAC`

**Назначение:** Исполнение промежуточного кода (ядро виртуальной машины) – минимальный набор.

Реализует основные команды интерпретации: переходы (`JMP`, `JSR`, `RTS`), циклы (`FOR`, `NEXT`), условные переходы (`IF`, `IFF`), вызов функций (`FN`), обработку массивов (`INDEX`, `ARRAY`), работу со стеком, преобразования типов. Содержит также реализацию арифметических операций для целых чисел (`SUM`, `SKIRT`, `SAND`, `IDIV`, `MOD`, `NOT`, `OR`, `AND` и др.).


## 11. `JMP.MAC`

**Назначение:** Расширенное ядро выполнения – дополнительные команды и работа со строками.

Включает подпрограммы для обработки строк (`NEWSTR`, `CONCAT`, `STR`, `CHR`, `INSTR`, `LEN`, `VAL`, `ASC`, `MID$`, `LEFT$`, `RIGHT$`), работы с памятью (`CLR`, `CLRMEM`, `FRE`), вызова пользовательских функций (`USR`, `FN`), управления файлами (`OPEN`, `CLOSE`, `EOF`, `INPUT#`, `PRINT#`), а также системные команды (`RENUM`, `DELETE`, `EDIT`, `AUTO`). Используется вместе с `JMIN.MAC`.


## 12. `MDBLOC.MAC`

**Назначение:** Инициализация модуля работы с диском (очень короткий файл).

Содержит только метку `MDINIT`, которая, вероятно, должна инициализировать драйвер диска. В представленном фрагменте просто записывает адрес `ILCDO` в вектор прерываний. Файл, возможно, неполный или используется как заглушка.


## 13. `MONIT.MAC`

**Назначение:** Главный монитор (директивный режим) и обработка ошибок.

Организует цикл «OK», ввод команд, запуск программ, обработку прерываний (`BREAK`), инициализацию векторов, вывод сообщений об ошибках. Содержит процедуры `START` (точка входа), `STAR` (основной цикл), `MONIT`, `CTRLC`, `BREAK`, `NEW`, `LIST`, `LLIST`, `RENUM`, `DELETE`, `CONT`, `RUN` и другие. Также включает таблицу сообщений об ошибках и их вывод (`MSTYPE`).


## 14. `NET.MAC`

**Назначение:** Пустой файл (содержит только `.SBTTL NET` и `.END`).

Предположительно, предназначался для поддержки сетевых функций, но в данной реализации не используется. Оставлен как заглушка.


## 15. `TRAP.MAC`

**Назначение:** Обработчики прерываний и библиотека встроенных функций.

Реализует системные прерывания (коды `TRAP 100` – `TRAP 130`) – синтаксический анализ выражений, ввод‑вывод, вызов функций (`RND`, `SQR`, `SIN`, `COS`, `EXP`, `LOG`, `INT`, `ABS`, `SGN`, `CSNG`, `CINT`, `INSTR`, `USR`, `FN`). Содержит таблицы ключевых слов для операторов и функций, парсер выражений с учётом приоритетов, а также подпрограммы преобразования типов и проверки синтаксиса.

Диспетчер `TRAP::` вызывает `Tnnn` по номеру через таблицу `ATRAP`; коды младше 100 (`TRAP 8`, `TRAP 13` и т.п.) - это не подпрограммы, а сразу коды ошибок, обрабатываемые в `ERROR`. Многие `Tnnn` (`T110`, `T113` и др.) при возврате сами сдвигают адрес возврата на стеке (`MOV R0,4(SP)` в `TRAP::`), тем самым выбирая, сколько слов кода после самой инструкции `TRAP N` пропустить у вызывающей стороны - этим реализованы условные/многовариантные переходы прямо по результату разбора (совпадение с ключевым словом, найден ли необязательный аргумент и т.п.), без явных условных переходов в коде компилятора. Основные `Tnnn`, используемые компилятором (`COMP.MAC`): `T100` - разбор выражения, `T101`/`T113` - сравнение с ключевым словом(-ами), `T102` - классификация символа (буква/цифра/иначе), `T106` - проверка конца оператора, `T110`/`T111` - разбор и поиск номера строки (`GOTO`/`GOSUB`/`RUN`/`RESTORE`), `T112` - пропуск пробелов, `T115` - разбор строкового аргумента (имя файла и т.п.), `T116` - необязательный аргумент через запятую, `T123`/`T124`/`T125` - разбор 3/2/1 целых выражений через запятую, `T127`/`T130` - проверка `(`/`)`.


## Структура сборки

Все файлы собираются с использованием условной компиляции (макросы `.IF EQ,MASINA-...`). Основной точкой входа является `START` в модуле `MONIT.MAC`. Для сборки под конкретную платформу (УКНЦ, БК‑0010, БК‑0011, ДВК) достаточно изменить значения в файлах настройки `GENUKC.MAC` / `GENUKD.MAC`.
